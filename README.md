# DCM术后恢复 RF–SHAP预测工具

这是一个可直接托管在 GitHub Pages 的纯静态临床研究计算器。网页在浏览器端复现最终锁定的300棵树随机森林，并为单个患者计算 Kernel SHAP 解释，不需要R、Python或服务器。

## 功能

- 输入7项常规术前指标；
- 输出术后1年未达到严重程度特异mJOA MCID的预测概率；
- 使用研究预设阈值0.50给出模型分类；
- 生成患者级SHAP贡献图和贡献表；
- 下载PNG图和CSV结果；
- 患者输入仅在浏览器内处理，不上传、不保存。

## 模型一致性

网页包含最终锁定RF的标准化参数和全部300棵决策树。发布前使用157个合成及混合测试点逐例比较网页与原R模型，最大概率误差为0；患者级SHAP也与R包 `kernelshap` 的精确模式逐变量核对。

## 隐私保护SHAP参考

公开网站不包含R模型对象、原始数据库或任何真实患者行。SHAP使用100例高斯Copula合成参考样本，它们在本地根据回顾性训练分区的边缘分布和秩相关结构生成，并已确认不等于任何观察患者记录。因此：

- RF预测概率与锁定R模型一致；
- 个体SHAP值解释的是同一RF，但其参考基线可能与论文中使用真实背景样本得到的图略有差异；
- SHAP是模型归因，不代表因果效应。

## 适用边界

阳性结局定义为术后1年mJOA恢复未达到最小临床重要差异（MCID）。模型完成了同中心前瞻性时间验证，但尚缺少地理外部验证和临床影响试验。本工具只是对患者预后提供参考，不能代替治疗方案。
