# DCM术后恢复 RF–SHAP预测工具

这是一个可直接托管在 GitHub Pages 的纯静态临床研究计算器。网页在浏览器端复现最终锁定的20套RF拟合（每套300棵树，mtry=2），对20个预测概率取平均，并为单个患者计算 Kernel SHAP 解释，不需要R、Python或服务器。

## 功能

- 输入7项完整的常规术前指标；缺失输入不在公开网页端插补，请勿用猜测值代替；
- 输出术后1年未达到严重程度特异mJOA MCID的预测概率；
- 使用固定研究分类阈值0.50给出模型分类，不将其视为已验证的临床干预阈值；
- 生成患者级SHAP贡献图和贡献表；
- 下载PNG图和CSV结果；
- 患者输入仅在浏览器内处理，不上传、不保存。

## 模型一致性

网页包含20套冻结RF各自的标准化参数和全部6000棵决策树，对应训练限定、折内20套插补及5折重复5次嵌套验证后的正式模型。发布前使用35个合成测试点及359例完整输入的留出验证患者进行本地核对（共394例），最大概率误差小于1e-12；真实患者测试数据不上传。两例合成患者的SHAP已与R包 `kernelshap` 0.7.0精确模式逐变量核对，误差小于1e-9。

## 隐私保护SHAP参考

公开网站不包含R模型对象、原始数据库、逐例验证预测、插补供体记录或任何真实患者行。完整输入无需调用冻结插补，因此可在不公开供体数据的情况下复现正式流程的完整输入预测。SHAP使用100例高斯Copula合成参考样本，它们在本地根据回顾性训练分区的边缘分布和秩相关结构生成，并已确认不等于任何观察患者记录。因此：

- RF平均预测概率与冻结的20套R模型一致；
- 个体SHAP值解释的是同一20套RF平均概率函数，但其参考基线可能与论文中使用真实背景样本得到的图略有差异；
- SHAP是模型归因，不代表因果效应。

## 适用边界

阳性结局定义为术后1年mJOA恢复未达到最小临床重要差异（MCID）。模型完成了同中心时间验证，但尚缺少地理外部验证和临床影响试验。本工具只是对患者预后提供参考，不能代替治疗方案。最新平均概率的内部验证AUC为0.891，时间验证AUC为0.850；校准仍不完善，不能据此宣称已证实临床干预获益。

## 文件

- `index.html`：网站页面；
- `www/site.js`：界面交互、下载和结果展示；
- `www/rf-engine.js`：20套RF平均概率推理和精确Kernel SHAP引擎；
- `www/shap-worker.js`：浏览器本地SHAP计算线程，患者输入不经网络发送；
- `model/rf-model-data.js`：模型版本清单、合成参考分布和校验样本；
- `model/20261025-mi20-v2/forest-*.bin.gz`：20套压缩RF推理参数；
- `tests/engine.test.cjs`：仅使用合成样本的公开回归测试，可用Node.js运行；
- `og.png`：社交分享预览图。
